# Changelog

## 1.2.0

- Add helper setup instructions and a download link in plugin settings.
- Find a separately installed helper in Applications or at a configured location.
- Stop capture if Obsidian exits, and force a stuck helper to quit after cancellation.
- Prefer the original editor when the same note is open in multiple panes.
- Keep a completed photo if the vault fails to save it, with a notice giving its path.
- Add reproducible plugin and universal helper builds, plus automated regression tests.
